uniq(1) - OpenBSD Man Page Flags
Source: https://man.openbsd.org/uniq.1

-c    Precede each output line with the count of the
      number of times the line occurred in the input,
      followed by a single space.

-d    Only output lines which have duplicates.

-f fields
      Ignore the first fields in each input line when
      doing comparisons. A field is a string of non-blank
      characters separated from adjacent fields by
      blanks, with blanks considered part of the
      following field.

-i    Regard lower and upper case ASCII characters as
      identical.

-s chars
      Ignore the first chars characters in each input
      line when doing comparisons. If specified with -f,
      the first chars characters after the first fields
      fields will be ignored.

-u    Only output lines which are unique.
