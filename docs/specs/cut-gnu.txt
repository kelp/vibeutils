Usage: cut OPTION... [FILE]...
Print selected parts of lines from each FILE to standard output.

With no FILE, or when FILE is -, read standard input.

Mandatory arguments to long options are mandatory for short options too.
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut-b\[1m-b, --bytes=LIST[0m]8;;\
         select only these bytes
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut-c\[1m-c, --characters=LIST[0m]8;;\
         select only these characters
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut-d\[1m-d, --delimiter=DELIM[0m]8;;\
         use DELIM instead of TAB for field delimiter
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut-f\[1m-f, --fields=LIST[0m]8;;\
         select only these fields;  also print any line that contains
         no delimiter character, unless the -s option is specified
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut-n\[1m-n[0m]8;;\
         (ignored)
      ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut--complement\[1m--complement[0m]8;;\
         complement the set of selected bytes, characters or fields
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut-s\[1m-s, --only-delimited[0m]8;;\
         do not print lines not containing delimiters
      ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut--output-delimiter\[1m--output-delimiter=STRING[0m]8;;\
         use STRING as the output delimiter;
         the default is to use the input delimiter
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#cut-z\[1m-z, --zero-terminated[0m]8;;\
         line delimiter is NUL, not newline
      ]8;;https://www.gnu.org/software/coreutils/cut#cut--help\[1m--help[0m]8;;\
         display this help and exit
      ]8;;https://www.gnu.org/software/coreutils/cut#cut--version\[1m--version[0m]8;;\
         output version information and exit

Use one, and only one of -b, -c or -f.  Each LIST is made up of one
range, or many ranges separated by commas.  Selected input is written
in the same order that it is read, and is written exactly once.
Each range is one of:

  N     N'th byte, character or field, counted from 1
  N-    from N'th byte, character or field, to end of line
  N-M   from N'th to M'th (included) byte, character or field
  -M    from first to M'th (included) byte, character or field
