POSIX touch - OPTIONS

  -a    Change the access time of file. Do not change the
        modification time unless -m is also specified.

  -c    Do not create a specified file if it does not
        exist. Do not write any diagnostic messages.

  -d date_time
        Use the specified ISO 8601 format timestamp:
        YYYY-MM-DDThh:mm:SS[.frac][tz]

  -m    Change the modification time of file. Do not
        change the access time unless -a is also specified.

  -r ref_file
        Use the corresponding time of the file named by
        ref_file instead of the current time.

  -t time
        Use the specified time in decimal format:
        [[CC]YY]MMDDhhmm[.SS]
