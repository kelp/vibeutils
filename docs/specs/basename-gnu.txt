Usage: basename NAME [SUFFIX]
  or:  basename OPTION... NAME...
Print NAME with any leading directory components removed.
If specified, also remove a trailing SUFFIX.

Mandatory arguments to long options are mandatory for short options too.
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#basename-a\[1m-a, --multiple[0m]8;;\
         support multiple arguments and treat each as a NAME
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#basename-s\[1m-s, --suffix=SUFFIX[0m]8;;\
         remove a trailing SUFFIX; implies -a
  ]8;;https://www.gnu.org/software/coreutils/manual/coreutils.html#basename-z\[1m-z, --zero[0m]8;;\
         end each output line with NUL, not newline
      ]8;;https://www.gnu.org/software/coreutils/basename#basename--help\[1m--help[0m]8;;\
         display this help and exit
      ]8;;https://www.gnu.org/software/coreutils/basename#basename--version\[1m--version[0m]8;;\
         output version information and exit

Examples:
  basename /usr/bin/sort          -> "sort"
  basename include/stdio.h .h     -> "stdio"
  basename -s .h include/stdio.h  -> "stdio"
  basename -a any/str1 any/str2   -> "str1" followed by "str2"
