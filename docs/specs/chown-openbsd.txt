chown(8) - OpenBSD Man Page Flags
Source: https://man.openbsd.org/chown.8

-H    If the -R option is specified, symbolic links on
      the command line are followed. Symbolic links
      encountered in the tree traversal are not followed.

-h    Treat symbolic links like other files: modify links
      instead of following them. The -h and -R options
      are mutually exclusive.

-L    If the -R option is specified, all symbolic links
      are followed.

-P    If the -R option is specified, no symbolic links
      are followed.

-R    Recurse. Where file is a directory, change the user
      ID and/or the group ID of the directory and all the
      files and directories in the file hierarchy below
      it.
